One unsent micro-confession — a To: line and the single line that was typed and never sent, written by a small TypeScript program to `entry.txt`.

## The confession

> To: the man who bought our house
>
> I still drive past on Sundays to check if you kept the lemon tree I planted the year my son was born

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
